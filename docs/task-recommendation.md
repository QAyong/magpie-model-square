# 任务推荐 · UI 设计

状态：v1 已实现。编程榜（SWE-bench + Aider）已进页面；写作 / 数学 / 中文等第二个任务的数据，主推位才会出现。目标：把「按任务选模型」做成**页首推荐区**——
参考 Magpie 插件广场的「今日推荐 / 下载最多 / 星标最多」三栏版式：
顶部一排推荐面板，下方保留现有目录浏览。数据来源结论见对话：
SWE-bench / Aider 可脚本直取，LMArena 走快照，SuperCLUE 人工录入。

## 0. 设计原则

1. **推荐在页首，浏览在下。** 打开页面先看到「本期榜单」面板区；
   向下是原有工具栏 + 全部模型，一行不改。
2. **面板是入口，列表是结果。** 面板里点「详情」跳到下方对应卡片并展开；
   面板底部「查看全部 ›」把任务上榜结果刷进下方列表。
3. **页面仍然离线。** 推荐数据打包进 `page/rankings.js`（同 catalog/prices 模式）。
4. **分数是相对的。** 推荐分只在当次快照的上榜模型内可比，
   面板与详情必须带「截至日期」，不冒充绝对能力。

## 1. 页面结构总览

```
页头（标题 + 布局/主题/币种，现状不变）
└─ ① 本期榜单区（新增，面板横排，可换行）
     ├ 综合推荐（主推位，单模型大卡）
     ├ 编程 Top 5（榜单面板）
     ├ 写作 Top 5
     └ …（数学推理 / 中文对话，数据到位自动出现）
└─ ② 工具栏（搜索 + 种类 + 厂商/排序，现状不变）
└─ ③ 模型列表（卡片网格，任务过滤时叠加徽章与排序联动）
```

- `rankings.js` 缺失或为空 → ① 整区隐藏，页面完全退化为现状。
- 面板数量随数据增长，flex 换行；窄屏下主推位独占一行，榜单面板两列/一列。

### 2.2 「查看全部 ›」→ 任务过滤模式（下方列表联动）

```
│ 🔍 搜索名称、ID、描述或厂商                                           /  │
│ (全部) (对话*) (图像━) (视频━) …  其余种类段禁用                          │
│                                   [厂商▾] [按推荐分▾]                    │
├──────────────────────────────────────────────────────────────────────────┤
│ [编程 · 上榜 6 个 ×]        按「编程」推荐 · 依据 SWE-bench/Aider/LMArena │
│                             数据截至 2026-11-14                          │
│ ┌───────────────────────────────┐ ┌───────────────────────────────┐      │
│ │ ⓵ ◆ DeepSeek V4.1        [⧉] │ │ ⓶ ◆ Claude Opus 5.5      [⧉] │      │
│ │    DeepSeek     推荐分 92     │ │    Anthropic    推荐分 90     │      │
│ │    ¥2.00 / ¥8.00   128K       │ │    ¥38.11 / ¥190.55   200K    │      │
│ └───────────────────────────────┘ └────────────────────────────────┘      │
```

- 过滤药丸（× 可清除）出现在 list-summary 行，替代之前的 chips 方案。
- 联动规则：进入 → 种类锁「对话」、其余种类段禁用、排序切「按推荐分」；
  退出 → 若排序仍为 `task` 还原 `latest`，种类恢复可选。
- 厂商、搜索照常叠加；`visibleCount` 重置，「继续显示」复用。

### 2.3 面板行「详情」→ 定位下方卡片

点击行或 [详情]：重置会隐藏该模型的筛选（种类→对话、清厂商、清搜索）→
`expandedId` 设为该模型 → 卡片 `scrollIntoView` → 展开详情。
主推位 [复制 ID] 走现有 `copyText`（含 `execCommand` 回退）。

### 2.5 空态与降级

- 任务过滤后被厂商/搜索过滤光：「按「编程」推荐 0 个模型……试试清除厂商筛选，或 [×]」。
- 某面板不足 5 个模型：有几行显示几行；0 个的面板不渲染。
- 整份榜单数据缺失：① 区隐藏，其余照旧。

## 3. 组件与状态明细

| 项 | 规格 |
| --- | --- |
| 榜单区容器 | `<section class="recommend">`，标签 + `.recommend-panels`（flex wrap）；JS 渲染 |
| 主推位 | 「综合推荐」= 各任务榜综合表现最佳者（见 §6），含推荐语、四格统计、[详情] [复制 ID] |
| 榜单面板 | 标题 + 来源小字 + 最多 5 行 + 「查看全部 N 个 ›」（N≤5 时隐藏该链接） |
| 行内 [详情] | 定位并展开下方卡片（§2.3），与卡片 hover 复制按钮互不影响 |
| 任务过滤药丸 | `.task-pill`，置于 `#result-count` 同排；× 清除 |
| 排序下拉 | 新增选项「按推荐分」（`sort='task'`），仍为自绘下拉，文案红线不变 |
| 卡片徽章 | `.rank-badge` 圆底序号、`.task-score`「推荐分 NN」，仅任务过滤模式显示 |
| 无障碍 | 面板序号 `aria-hidden`，语义放详情文本；计数行 `aria-live="polite"`；面板行可聚焦 |
| 持久化 | layout/theme/currency 照旧；**任务过滤与面板不写入 magpie.options** |

## 4. 数据结构（`page/rankings.js`，同步脚本生成、单行大对象）

```js
export const RANKINGS = {
  asOf: '2026-11-14',
  featured: { id: 'deepseek/deepseek-v4.1', reasons: ['编程 第1', '写作 第3'] },
  sources: {
    'swe-bench': { name: 'SWE-bench Verified', url: 'https://www.swebench.com/' },
    aider: { name: 'Aider polyglot', url: 'https://aider.chat/docs/leaderboards/' },
    lmarena: { name: 'LMArena', url: 'https://arena.ai/' },
    superclue: { name: 'SuperCLUE', url: 'https://www.superclueai.com/' },
  },
  tasks: {
    coding: {
      label: '编程',
      headline: 'swe-bench',        // 面板行显示的头条信号
      sources: ['swe-bench', 'aider', 'lmarena'],
      models: [
        { id: 'deepseek/deepseek-v4.1', score: 92, rank: 1,
          evidence: { 'swe-bench': 74.5, aider: 55.1, lmarena: 1520 } },
      ],
    },
    writing: { /* label 写作 … */ },
    math: { /* label 数学推理 … */ },
    'chinese-chat': { /* label 中文对话 … */ },
  },
};
```

- `id` 一律是 **catalog 原生 id**：别名换算在同步脚本完成，页面不做名字猜测。
- `evidence` 保留原始量纲（%、Elo），`score` 是归一化推荐分；`headline` 决定面板行展示哪个原始值。
- `featured.reasons` 由同步脚本按模板生成中文短语，页面直接拼接。
- 同步脚本幂等：任何源失败只生成有数据的任务/面板，页面自动适配。

写作/数学/中文随 LMArena 数据接入补齐；权重只写在同步脚本里，页面不感知。

## 6. 打分与主推规则（同步脚本内实现）

1. 每个信号在**当次快照该任务的上榜模型内** min–max 归一化到 0–100；
2. 模型缺某信号时权重在现有信号间重分配（至少 1 个信号才上榜）；
3. 任务推荐分 = 加权平均四舍五入；同分同名次，按分数降序输出；
4. 主推位 = 在 ≥2 个任务上榜的模型里取**平均名次**最好者；并列取推荐分高者；
5. 推荐语模板：`{任务} 第{n}` 用「·」连接 + 价格句；无证据不硬造分数，宁缺毋滥。

## 8. 红线核对

- 页面零网络：✅ 数据打包，脚本侧联网。
- 不动原生 `select`、不改「厂商」文案：✅ 排序仍是自绘下拉。
- 不往 `<html>` 写 `data-theme`：✅ 新样式走页面自己的主题变量。
- `magpie.options` 每秒一次：✅ 不新增写入键。
- 复制回退 `execCommand`：✅ 复制走现有 `copyText`。
- 数据文件模式一致：✅ `rankings.js` 为生成式单行大对象。
- 「详情」定位会重置筛选：属页面内导航，不触碰偏好持久化。

## 9. 明确不做的（v2 候选）

- 面板里放「安装」类主按钮（模型无安装语义，详情+复制已够）。
- 性价比模式（推荐分 ÷ 价格）。
- 角色扮演/翻译/法律等 OpenRouter 用量榜（需 key，且要区分「热度」与「质量」徽章）。
- 工具调用/Agent 任务（AA Agentic Index）、长文本、嵌入任务（MTEB）。
- 面板轮换「今日推荐」随机化（快照期内固定，保证可复现）。
